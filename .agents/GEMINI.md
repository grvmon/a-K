# Design Guidelines

- **Container Widths**: The maximum container width across all pages should be 1280px (usually with a 2rem padding, yielding 1216px of active content area), unless the user explicitly requests a different width for a specific page. This ensures a consistent, wide cinematic layout for images and structural blocks across the entire site.
- **Editorial Typography**: While the outer container should stretch to 1280px, paragraph text and reading columns should remain constrained to roughly 760px to maintain optimal editorial line length (70-80 characters) inspired by Stripe/Notion/Apple.
