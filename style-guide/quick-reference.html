1. Wordmark & Logo 01
  • Wordmark: Strictly lowercase acre&key set in Josefin Sans (Weight 400).
  • Proportions: Ampersand (&) sits baseline-aligned without scaling tricks.
  • Clear Space: Minimum $1\times$ height of the "k" on all 4 perimeters.
  • Colorways: Obsidian Black (#2B2D31) on light canvas; Pure White (#FFFFFF) on dark surfaces.
  • Banned: No gradients on logo, no uppercase, no icon symbol separation, no drop shadows.

3. Typography System 03
  • Display & Headings: Marcellus, serif. Strictly weight 400. Faux-bolding is strictly banned.
  • Body & UI Elements: Manrope, sans-serif (Weights: 400 Regular, 500 Medium, 600 Semi, 700 Bold).
  • Heading Case: Strictly Sentence case across all hero titles and H2/H3 display headings.
  • Exclamation Marks: 100% Banned. Tone is clinical, objective, and institutional.
  • Measurements: Title Case with periods (e.g. 3,150 Sq.Ft.). Commas required for values >999.
  • Currency: Always ₹ with space (e.g. ₹ 3.10 Cr).
4. Geometry & Spacing 04
  • Corner Radius: Strictly 4px across cards, buttons, modals, badges, and form inputs. (No 0px brutalist, no 8px soft, Zero pill shapes).
  • Borders & Dividers: Strictly 0.5px hairline (rgba(85, 85, 90, 0.2)) mimicking luxury architectural financial dossiers.
  • Functional Iconography: Purely functional un-filled line icons with strict 2px stroke in Obsidian Black (#2B2D31) or Slate (#55555A). Permitted only when adding analytical clarity (Diligence Checks, Statutory Fees, Dimensions, Timeline).
  • Container Width: Max 1280px with 2rem side padding.
  • Fibonacci Spacing: 4px (xs), 8px (sm), 16px (md), 24px (lg), 40px (xl), 64px (2xl), 104px (3xl).
  • Cards: Zero default drop shadows. Depth achieved via whitespace, 0.5px hairlines, and typography hierarchy.
5. Photographic Art Direction 05
  • Cinematic Desaturation: All 3D builder renders must apply filter: saturate(0.85) contrast(1.05); for a moody, cohesive architectural grade.
  • Anchored Gradient Rule: Never place raw text on images. Always overlay Obsidian Black gradient: linear-gradient(to top, rgba(10, 10, 11, 0.95) 0%, rgba(10, 10, 11, 0) 60%) guaranteeing 19.8:1 AAA contrast.
  • Aspect Ratios: Standard property hero renders: 16:9. Persona cards: 3:4. Floorplans: 4:3.
  • Hover Dynamics: No physical card lifts. Smooth 0.4s image scale (1.03) or subtle dimming.

8. Contrast & A11y Rules 08
  • Body & Metadata: Strict $\ge 7.0:1$ WCAG AAA (Muted Slate `#55555A` = 7.10:1; Text Copper `#804526` = 7.19:1).
  • Headings: Obsidian Black `#2B2D31` on Titanium = 13.2:1 (AAA).
  • Focus Indicator: 2px solid ring in `--text-copper-aaa` (light) or `--highlight-peach` (dark). Must meet $\ge 3.0:1$.
  • Disabled State: opacity: 0.45; cursor: not-allowed; pointer-events: none; (WCAG SC 1.4.3 exemption).
  • Inline Links: 1px underline in `--text-copper-aaa` with 4px offset. Never default browser blue.
9. AI Agent Implementation Guardrails 09
  • Token Canonical Root: All variables live in website.css. Never hardcode hex values in HTML.
  • Zero Banned Vocabulary: Never generate marketing superlatives ("luxury masterpiece", "hurry up", "unbeatable deal").
  • Strict Geometry: Reject any CSS with border-radius: 999px, border-radius: 8px, or heavy drop shadows.
  • Global Nav/Footer: Always use the standard site header & footer. Never create custom simplified variants.
  • Compliance Checks: Verify RERA numbers and DPDP non-prechecked consent blocks on all lead forms.
